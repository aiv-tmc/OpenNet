# OpenNet

peer-to-peer network for distributed computing

<!-- Install -->
## Install

You must have [project dependencies](https://github.com/aiv-tmc/Paxsy#dependencies) installed 

1. Clone the repository:  

`$ git clone https://github.com/aiv-tmc/OpenNet.git`  

2. Go to the directory with the code:  

`$ cd ~/Download/OpenNet/`  

3. Start making the program:  

`$ cargo build --release`  

4. Start program:

`$ cargo run --release`
